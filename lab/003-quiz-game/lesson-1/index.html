lesson 01 / question detective

我是出题官

不是把 AI 给的题直接搬进游戏，而是像一个较真的出题官：选主题、出初稿、查证据、盖印章，最后做出 10 道经得起追问的好题。

  1. 01
    选主题越聚焦越好玩。
  2. 02
    指挥 AI用模板生成 10 道初稿。
  3. 03
    查证据为每个答案找权威出处。
  4. 04
    盖印章只有通过的题才进游戏。

mission 02 / 第一关

选一个真正好奇、足够聚焦的主题。

不要写泛泛的「动物」，改成「动物奇葩睡觉姿势」才有意思。主题会写进你的出题提示词和最终题库文件。

选择一个知识主题

选一个方向，再把它改成一个具体的题目范围。

mission 02 / 第二关

用出题模板，请 AI 生成 10 道初稿。

模板只有六行，但三块积木都在：设定角色、明确任务、立好边界。把【我的主题】换成你刚才写的主题，再发给课堂智能体。

出题提示词

主题没填时会显示「待补充」，不会替你编一个。

  1. 替换主题词把模板里的【我的主题】换成你选好的具体主题。
  2. 发送给 AI粘进课堂智能体，等 10 道题全部生成。
  3. 通读初稿看不懂的地方请 AI 重写，但不要直接相信答案。
final tool / 题库整理助手
AI题库整理与文件生成助手
完成 10 道核验题后，把下面这段提示词原样复制给 AI，再附上你的题目。它会按固定格式整理成 Markdown 和 JSON 两个文件。
你是一名专业的题库数据整理助手。
我会提供一组已经生成好的知识问答题目，请你将这些题目整理成两个文件：
Markdown 文件（.md）：方便人类和AI阅读、修改和扩充。
JSON 文件（.json）：方便计算机程序读取，未来可以用于制作知识问答游戏。
一、基本要求
完整保留我提供的所有题目。
不得擅自修改题目、选项、正确答案和答案解释。
不得删除任何题目。
不得自行增加未经提供的题目。
如果发现题目缺少信息或存在格式问题，请标记出来，不要自行编造。
两个文件中的题目数量、题目内容和正确答案必须完全一致。
二、Markdown文件格式要求
文件名称：主题名称.md
按照以下结构整理：
主题名称
题库基本信息
题库名称
题库ID
知识分类
适合年龄
题目数量
创建日期
版本号
题目列表
每道题按照以下格式整理：
第01题
题目ID：
题目：
选项：
A.
B.
C.
D.
正确答案：
答案解释：
核验关键词：
资料来源：如果原题没有提供，填写「待补充」
核验状态：如果原题没有提供，填写「待核验」
每道题独立成块，题目编号连续。
三、JSON文件格式要求
文件名称：主题名称.json
使用标准JSON格式，结构如下：
{
"bank_id": "ANIMAL-SLEEP-001",
"title": "主题名称",
"category": "知识分类",
"age_range": [9, 12],
"version": "1.0",
"question_count": 10,
"questions": [
{
"id": "ANIMAL-SLEEP-001-Q001",
"type": "single_choice",
"question": "题目内容",
"options": [
{"key": "A", "text": "选项A"},
{"key": "B", "text": "选项B"},
{"key": "C", "text": "选项C"},
{"key": "D", "text": "选项D"}
],
"answer": "B",
"explanation": "答案解释",
"keywords": ["关键词1", "关键词2"],
"source": [],
"verification": "pending"
}
]
}
注意：
每道题必须包含4个选项。
answer只能填写A、B、C、D。
verification使用pending、verified、disputed、deprecated四种状态之一。
不得在JSON中添加注释。
必须保证JSON语法正确，可以被程序直接解析。
所有题目都必须完整写入，不允许使用省略号代替内容。
四、文件生成与检查
完成整理后，请执行以下检查：
统计原始题目数量。
检查Markdown和JSON中的题目数量是否一致。
检查每道题是否有4个选项。
检查答案是否为A、B、C、D之一。
检查题目ID是否唯一。
检查题目内容、选项、答案和解释在两个文件中是否一致。
检查JSON是否符合标准语法。
五、最终交付要求
请直接生成两个可以下载的文件：
主题名称.md
主题名称.json
不要只在聊天窗口展示代码，也不要只给我复制保存的文本。
请将两个文件分别生成并提供下载链接。
如果文件生成失败，请明确告诉我原因，不要假装已经生成。
现在请等待我提供题目内容。
提示词按用户提供的原文呈现，没有改写或精简。
