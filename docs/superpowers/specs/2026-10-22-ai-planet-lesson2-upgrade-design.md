# AI星球第 2 节课｜升级工坊设计

> 状态：方案已在对话中逐项确认，本文用于实现前的最终书面审核。
> 日期：2026-10-22
> 范围：实验 001「AI星球」的第 2 节课工具；不改第 1 节课的七步生成器
> 课堂依据：用户提供的 `AI_Planet_Upgrade_Mission.pptx`（15 页全图，逐页已读）

## 一、这节课要解决什么

第 1 节课已经产出一个 AI 生成的网站 1.0。第 2 节课要把它升级成 2.0，重点三件事：头像、鼠标特效、屏幕宠物。

孩子打字慢，所以**不能让孩子自己写修改指令**。工具要把这三件事变成可点选的卡片，最后合成一段「修改型」中文提示词，孩子复制粘贴即可。

### 目标

- 四步点击完成升级方案，全程不需要打字。
- 产出的提示词**必须在原网站上修改**，不能重新生成一个网站。
- 提示词里写清楚：保留什么、只改什么、不要做什么、完成后怎么自查。
- 提供可玩预览，让孩子「玩着选」而不是「读着选」。
- 生成路演卡，直接回答 PPT 第 14 页的三个问题。

### 不做

- 不做准备/备份步骤（上课时老师口头讲，孩子不会打开工具）。
- 不做「必须保留」的勾选（第 1 节课的内容本身尚未固定，勾选无意义）。
- 不收集姓名、学校、照片；不上传头像照片。
- 不使用 `localStorage`/Cookie；不联网；不接数据库。
- 不做整页鼠标尾焰（只在预览框内演示，避免干扰填写）。

## 二、页面与入口

- 新路由：`/lab/001-ai-planet/upgrade/`，标题「第 2 节课 · AI星球升级工坊」。
- 第 1 节课页面 `/lab/001-ai-planet/` 只做两处增量：加「第 1 节课」标签、加「进入第 2 节课」入口。七步生成器内容不动。

## 三、四步流程

### 第 1 步 头像升级（必做）

六个选项，最多选 3 个，默认预选「眼睛跟着鼠标看」和「发光呼吸」：

| id | 标签 | 说明 |
|---|---|---|
| `follow-cursor` | 眼睛跟着鼠标看 | 鼠标移动时，头像的眼睛会跟着转 |
| `head-pat` | 摸头有反应 | 鼠标移到头顶，头像会眯眼、轻轻弹一下 |
| `blink` | 会眨眼 | 每隔几秒眨一次眼 |
| `glow` | 发光呼吸 | 头像周围有一圈慢慢变亮变暗的光 |
| `float` | 轻轻浮动 | 头像上下轻轻飘 |
| `expression` | 换表情 | 鼠标停留时换一个表情 |

校验：至少 1 个，最多 3 个。

### 第 2 步 鼠标特效（选做）

单选，默认「这次不加」：

| id | 标签 |
|---|---|
| `none` | 这次不加 |
| `stardust` | 星尘拖尾 |
| `rainbow` | 彩虹拖尾 |
| `bubbles` | 气泡上浮 |
| `pixel` | 像素方块 |
| `ripple` | 点击涟漪 |

### 第 3 步 屏幕宠物（挑战）

类型单选，默认「这次不加」：

| id | 标签 |
|---|---|
| `none` | 这次不加 |
| `robot-dog` | 小机器狗 |
| `cat` | 小猫 |
| `dinosaur` | 小恐龙 |
| `robot` | 小机器人 |
| `fox` | 小狐狸 |
| `octopus` | 小章鱼 |
| `custom` | 自己描述 |

动作多选，最多 2 个：跟着鼠标走 / 在角落打盹 / 点一下会跳 / 说一句欢迎语。

宠物名字可选（最多 20 字）。选「自己描述」时，描述必填（最多 40 字）。

### 第 4 步 检查并生成

汇总 → 生成提示词 → 复制 → 自检清单 → 路演卡。

## 四、提示词模板

固定骨架，段落按选择动态省略（选了「这次不加」就整段不出现，不留空标题）：

```
请在我上一条消息做好的网站基础上继续修改，做出「我的AI星球 2.0」。
不要重新做一个新网站。

一、必须保留
网站名字、自我介绍、已有内容板块、原来的主色和布局都先保留。
如果某个改动会影响到这些内容，先停下来告诉我，不要直接删改。

二、这次只改这些地方
1. 头像：<选中的头像效果，用中文顿号连接>。
2. 鼠标特效：<选中的特效描述>。
3. 屏幕宠物：<宠物类型 + 名字 + 动作>。

三、可以自由发挥
在不破坏上面内容的前提下，细节你可以自己决定。

四、不要做的事
不要删除我没提到的内容；不要编造我的经历、奖项和事实；
不要添加我没有要求的板块；特效不要挡住文字和按钮。

五、完成后请告诉我
1. 你改了哪些地方。
2. 哪些地方需要我自己检查。
```

## 五、可玩预览（P1）

- 头像：内联 SVG 小脸；鼠标在预览框内移动时眼珠跟随，限制在眼眶范围内；鼠标进入头顶热区时眯眼 + 回弹 + 气泡文字。
- 尾焰：仅在预览框内 canvas 演示，五种效果可现场切换。
- 宠物：预览框内可切换宠物，跟随鼠标、点击会跳。
- 触屏（`pointer: coarse`）不启用拖尾，改为点击涟漪。
- `prefers-reduced-motion: reduce` 下全部静态，所有选项文字仍完整可读。
- 预览不阻塞填写；预览失败时选项卡照常可用（脚本用 `try` 隔离，不抛到全局）。

## 六、改动边界（只进提示词）

不做勾选，固定写进提示词第一节「必须保留」与第四节「不要做的事」。

## 七、路演卡

按 PPT 第 14 页三问生成：

1. 请介绍自己的网站（你的网站是关于什么的？你希望别人了解什么？）
2. 相对 1.0 做了哪些改进？（你增加或修改了什么？哪一个变化是你最满意的？）
3. 未来你还想如何改善它？

第 1、3 问给空行让孩子现场说；第 2 问用孩子的选择自动填一句。

## 九、验收标准

- 四步可键盘完成，焦点可见。
- 「这次不加」的段落不出现在提示词里。
- 头像 0 个或超过 3 个时阻止下一步并给出中文提示。
- 提示词首行为「请在我上一条消息做好的网站基础上继续修改」，且包含「不要重新做一个新网站」。
- `prefers-reduced-motion: reduce` 下无动画、信息不丢失。
- 375 / 768 / 1440 三档无横向溢出。
- `pnpm test` 通过且 skipped 为 0。
