# MakerX HTML 动态首屏设计规格

日期：2026-10-15  
状态：用户已确认，进入实现

## 目标

把首页首屏从“展示一张首屏图”重构为“可交互的网页舞台”：进入页面时先看到一个严格占满首屏的 MakerX 品牌场景，文字、轨道、几何体和网格都是真实的 HTML/CSS/SVG 元素，滚动后才进入项目档案。

参考 `haoqi.design` 的信息层级、克制留白、滚动叙事和微交互节奏；不复制其代码、字体、文案、素材或独特视觉作品。用户提供的 `references/MakerX AI造物实验室.png` 继续作为构图、色彩和品牌关系的参考，但不作为首屏主体图片展示。

## 页面结构

```text
100svh Hero 舞台
  顶部导航：MakerX / 项目档案
  左上：MAKE / EXPLORE / CREATE / TOGETHER
  右上：用 AI ｜ 让创意成为现实
  中央：MakerX + AI 造物实验室 + 品牌主张
  背景：冰蓝网格、辅助线、自绘 SVG 轨道和几何体
  底部：项目制学习 / AI 工具 / 数字作品集 + 滚动提示

滚动后的项目档案区
  项目会一直长出来。
  课程与项目持续研发中
  探索造物项目

页脚
```

Hero 不使用左右栏，不把 PNG 当作 `<img>` 主视觉，不突出实验 001，也不重复堆叠完整品牌名。品牌名以真实 HTML 文本存在一次：`MakerX` 与其下方的 `AI 造物实验室`。

## 视觉和动效

- 底色使用与参考图一致的冰蓝 `#E9F2FD`，标题使用深墨 `#111315`，青色和长春花蓝仅用于装饰。
- 通过 CSS 背景网格、细分隔线和等宽小标签建立实验室 / 坐标系统感。
- 通过自绘 SVG 绘制轨道、球体、星芒和渐变几何体；不增加 Three.js、GSAP、WebGL 或外部字体。
- 首屏进入时导航、角标、品牌文字和 SVG 装饰错峰出现；只动画 `opacity` 与 `transform`。
- 轨道缓慢旋转、球体沿轨道轻微移动、几何体低幅漂浮；不做高频闪烁或影响阅读的视差。
- 桌面端精细指针移动时显示低幅度粒子尾焰；Canvas 只作为装饰层，`pointer-events: none`，触摸设备不启用。
- `prefers-reduced-motion: reduce` 下关闭所有持续动画和入场过渡，内容直接可见。
- 无 JavaScript 时所有文字、导航和滚动入口仍然可见可用。

## 响应式行为

- Hero 使用 `min-height: 100svh`，首屏不提前露出项目档案区。
- `>= 1024px` 保持中央大字和完整 SVG 构图；角标分布在四角。
- `768–1023px` 缩小字阶和装饰范围，保持中央构图。
- `< 768px` 让中央标题分两行，减少 SVG 装饰数量和轨道尺寸，仍保持单列和无横向溢出。
- 所有导航和滚动目标保留至少 `44px` 触控区域。

## 内容边界

- 首屏文案只描述 MakerX 的造物方式，不编造课程数量、模块数量、作品数量或具体实验细节。
- 项目档案区保持品牌级占位，具体项目以后再接入内容系统。
- 不收集表单数据，不接入分析、广告、评论或儿童个人信息。

## 验收标准

- 首页进入时 Hero 高度覆盖 `100svh`，项目档案需要滚动后才出现。
- `src/pages/index.astro` 不以 `makerx-hero.png` 或任何 PNG 作为 Hero 主体。
- `MakerX`、`AI 造物实验室`、主张、角标和档案入口是可复制的 HTML 文本。
- SVG 装饰在桌面、平板、手机三档视口不溢出、不遮挡核心文案。
- 动效包含错峰入场、轨道/几何体运动和滚动揭示，并支持 reduced motion。
- `pnpm test`、`pnpm check`、`pnpm build` 全部通过。
- 浏览器只记录已测量的尺寸、状态和请求结果；视觉观感由用户在本地预览中最终确认。
