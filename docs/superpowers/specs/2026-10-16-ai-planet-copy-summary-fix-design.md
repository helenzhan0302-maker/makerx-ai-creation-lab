# AI星球复制与汇总展示修复方案

> 状态：已根据浏览器反馈确认，等待实现。
> 日期：2026-10-16

## 目标

修复 AI星球项目页的两个体验问题：

1. 在腾讯云 IP 的 HTTP 地址下，点击“复制提示词”能够优先自动复制，不再因为 `navigator.clipboard` 不可用而直接失败。
2. 汇总草图中的每一项使用“标签：答案”的同一行格式，保留答案较长时的自然换行能力。

## 约束

- 不引入数据库、登录、第三方复制服务或新的运行时依赖。
- 不把提示词上传到服务器；复制仍然只发生在当前浏览器。
- 复制反馈只有在复制 API 或兼容降级方案返回成功后才显示成功文案。
- 两种复制方式都失败时，保留可访问的提示词文本，并提示用户长按或拖动选择复制。
- 汇总继续使用语义化 `dl` / `dt` / `dd`，不使用 `innerHTML`。
- 不改变现有提示词内容格式，只改变汇总页面的视觉呈现。

## 方案

### 复制

在 `src/lib/ai-planet-builder.mjs` 增加无 DOM 的复制策略结果约定，或在组件脚本中使用一个小型浏览器适配函数：

1. 如果 `navigator.clipboard.writeText` 存在，先尝试它。
2. 如果不存在或 Promise 拒绝，创建短生命周期的隐藏 `textarea`，写入提示词，选中后调用 `document.execCommand('copy')`。
3. 无论 API 是否存在，都以真实返回结果决定反馈文案；不把“调用完成”当作“复制成功”。
4. 清理临时 textarea，失败时将焦点回到提示词文本区域。

这样可以覆盖当前公网 HTTP 页面中的非安全上下文，也兼容部分移动浏览器和旧浏览器。

### 汇总

`renderSummary()` 继续生成一个 `.summary-row`，但每行改为：

```html
<dt>网站名字：</dt>
<dd>123</dd>
```

CSS 使用两列 grid 或 flex 让 `dt` 与 `dd` 在同一行开始；`dd` 设置可换行，避免开放式内容撑破页面。标签统一在 `dt` 文本中添加全角冒号，答案仍通过 `textContent` 写入。

## 验收标准

- 在公网 HTTP 页面点击“复制提示词”，成功时显示“已复制，可以交给 AI 制作网站啦！”。
- 当 Clipboard API 被禁用或拒绝时，兼容复制分支仍能报告成功；两种方案都失败才显示手动复制提示。
- 汇总页显示“网站名字：123”等同一行结构；长答案可以换行，不产生横向溢出。
- 现有 7 个测试与新增复制/汇总契约测试全部通过。
- `pnpm check`、`pnpm build` 通过；部署后公网首页、AI星球页和原有站点均保持 `HTTP 200`。
